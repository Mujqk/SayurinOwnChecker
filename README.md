> **Sayurin Checker** — инструмент автоматической проверки читов, разработанный специально для сервера **Baza CS2**.
> Обеспечивает быструю, точную и удобную проверку игроков без лишних ручных действий.

<br/>

---

## ⚡ О проекте

Sayurin Checker создан для упрощения работы администраторов и чекеров на серверах CS2. Вместо десятков ручных проверок — один инструмент, где всё под рукой: от анализа программ до истории USB-устройств и VAC-банов.

---

## 🔍 Возможности

### 🤖 Автопроверка
- **Автоматическая система проверки** — более **16 встроенных программ** для обнаружения читов
- **Специальные подписанные буферы обмена** — уникальные clipboard-профили для отдельных типов проверок
- **Автопроверка биндов** — мгновенный анализ назначенных клавиш

---

### 🚫 Баны и Steam

| Функция | Описание |
|---|---|
| 🔴 Проверка банов | Автоматическая проверка банов на стороне сайта |
| 🎮 VAC-бан | Просмотр VAC-бана напрямую через Steam аккаунт |
| 🔗 Steam-профиль | Быстрый переход в профиль игрока одним кликом |

---

### 💾 Вкладка USB

Полная история подключённых устройств:

- 🖱️ Периферия (мышь, клавиатура, и др.)
- 🔌 Все флешки и накопители
- 📅 Дата и **точное время** подключения / отключения каждого устройства

---

### 📁 Вкладка Папки

Больше не нужно вручную прописывать пути через `Win + R`:

- Быстрый доступ к системным папкам
- Готовые пути к `.exe` файлам прямо из реестра

---

### 🌐 Вкладка Сайты

Быстрый доступ к нужным ресурсам:

- 📧 Почтовые сервисы
- 💳 Платёжная информация и сервисы оплаты

---

### 🛠️ Вкладка Дополнительно

Запуск системных инструментов прямо из чекера:

- ⌨️ Экранная клавиатура
- 🌐 Параметры сети
- ⚙️ Службы Windows
- 🎮 Панель управления NVIDIA

---

### 🖥️ Системная вкладка

- 📊 Основные характеристики системы (CPU, GPU, RAM и др.)
- 🕵️ **Детектор виртуальных машин (VM)** — определяет, запущен ли чекер в виртуальной среде
